Implementation of JEPA (Joint Embedding Predictive Architecture)

for language model pretraining from scratch in Parameter Golf.

val\_bpb: 1.2699 \| 135MB \| 8×H100 SXM, 600s \| Seed 1337

JEPA predicts embeddings instead of tokens — learning meaning rather

than surface statistics. Two parallel encoders: context encoder (trained

via gradients) and target encoder (EMA copy, no gradients).

Loss = CE + 0.1 × MSE(predicted\_embedding, target\_embedding)

Model is 135MB, way over 16MB limit. (An overlook mistake was to not forsee the size so that the hyperparams should be adjusted accordingly; model dimension and layers)

Next steps: mid-layer JEPA + size reduction to fit record track.

Submission: records/track\_non\_record\_16mb/2026-04-08\_JEPA\_baseline/
