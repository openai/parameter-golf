## Approach

Single shared transformer block applied 12 times instead of independent layers.

Reduces unique params from ~25M → 4.7M, freeing budget to go wider (dim=768).

Key changes from baseline:

- Depth recurrence: 1 shared Block × num\_passes (default 12)
- U-Net skip connections: encoder passes store activations, decoder passes consume in reverse
- x0 residual mix: original embedding injected at every pass for stability
- Wider model: MODEL\_DIM=768, NUM\_HEADS=12 vs baseline 512/8

## Result

- val\_bpb: 1.4061 (after int8 + zlib roundtrip)
- Artifact size: 4.39MB / 16MB budget
- Parameters: 4,726,284
- Hardware: RTX 4090, ~45s training time

## Run command

MODEL\_DIM=768 NUM\_HEADS=12 NUM\_KV\_HEADS=4 NUM\_PASSES=12

MATRIX\_LR=0.02 WARMDOWN\_ITERS=600 MAX\_WALLCLOCK\_SECONDS=0

TRAIN\_BATCH\_TOKENS=524288 PYTORCH\_CUDA\_ALLOC\_CONF=expandable\_segments:True

torchrun --standalone --nproc\_per\_node=1 train\_gpt\_recurrent.py
