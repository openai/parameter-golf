## What's Included

### 1. Code Changes to `train_gpt_mlx.py`
✓ **Focal Loss** (lines ~455-500)
  - Implements focal loss weighting: `loss * (1 - p_t)^gamma`
  - Controlled by `FOCAL_GAMMA` env var (default: 0 = standard CE)
  - Enables Experiments E06, E08, E10

✓ **Fast Validation** (lines ~765-770)
  - Truncates eval set when `MAX_VAL_TOKENS` is set
  - Turns 28-min eval into ~2-min eval for rapid iteration
  - 0 (default) = use full 62M token set
  - 1000000 = use only first 1M tokens (recommended for --fast mode)

✓ **New Hyperparameters**
  - `focal_gamma: float` — focal loss gamma (default: 0.0)
  - `eval_temperature: float` — temperature scaling (default: 1.0)
  - `eval_sliding_stride: int` — sliding window stride (default: 0)
  - `max_val_tokens: int` — validation set size limit (default: 0 = unlimited)

### 2. Experiment Infrastructure

**`experiments/experiment_configs.py`** (135 lines)
- Defines all 10 experiments as dicts
- Experiment structure: id, name, description, env_vars, code_change_required
- Functions: `get_experiment()`, `to_env_string()`, `list_experiments()`

**`experiments/run_m4_experiments.sh`** (bash script)
- Sequentially runs experiments
- Flags:
  - `--fast`: Sets `MAX_VAL_TOKENS=1000000` (2-min eval, ~12 min/run)
  - `--single <id>`: Run one experiment (e.g., `--single E03`)
- Auto-skips if log exists
- Generates summary table at end

**`experiments/analyze_results.py`** (Python script)
- Parses all `logs/exp_*.txt` files
- Extracts: BPB, steps, artifact size, training time
- Compares vs baseline (3.2178 BPB)
- Outputs markdown report to `experiments/results_summary.md`

## Implementation Details

### How Focal Loss Works (E06, E08, E10)
```
Standard CE: loss = -log(p_t)
Focal CE: loss = -log(p_t) * (1 - p_t)^gamma
```
This down-weights "easy" tokens (high p_t) and focuses on hard tokens (low p_t).
- gamma=0: standard CE (no focal effect)
- gamma=2: moderate down-weighting (used in all experiments)

### How Fast Mode Works
```bash
# Fast mode: use only first 1M tokens out of 62M validation set
MAX_VAL_TOKENS=1000000 python3 train_gpt_mlx.py

# This makes validation 28x faster (1M/28M ≈ 2 min vs 28 min)
# BPB on truncated set is not directly comparable to baseline
# But relative ranking of experiments should be preserved
```
